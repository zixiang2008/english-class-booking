## 2. รายการฟีเจอร์

### 2.1 หน้าครู (`/admin.html`)

- **ภาพรวม:** คลาสของฉัน ยืนยันแล้ว รอยืนยัน จำนวนการจอง จำนวนนักเรียน จำนวนครูบนเว็บ
- **ประกาศคลาส:** ชื่อคลาส ช่องประกาศ (≤100 ตัวอักษร) เขตเวลา วันที่ เวลาเริ่ม/สิ้นสุด **รูปแบบการเรียน** จำนวนที่รับ สถานะ
  - **ออนไซต์** (ค่าเริ่มต้น): สถานที่ + ลิงก์ Google Maps บังคับทั้งคู่
  - **ออนไลน์**: แพลตฟอร์ม (เลือก 1 จาก 8) + ลิงก์ประชุม (บังคับ รับลิงก์ `https://` ใดก็ได้) + หมายเหตุรหัสห้อง/รหัสผ่าน (ไม่บังคับ) ฟิลด์แผนที่จะซ่อนและไม่บังคับอีก
- **แก้ไขคลาส:** ทุกฟิลด์ เมื่อบันทึกจะเพิ่ม `revision` และเขียนประวัติการเปลี่ยนแปลง
- **เปลี่ยนสถานะ:** รอยืนยัน / ยืนยันเปิดสอน / ยกเลิก / จบแล้ว พร้อมหมายเหตุได้
- **ฟีดการจองสด:** ชื่อนักเรียน ชื่อผู้ใช้ เบอร์โทร คลาส เวลาเรียน เวลาที่จอง
- **จัดการตารางรายสัปดาห์:** ช่องวนซ้ำ 7×8 แบบ v2 ยังใช้ได้
- **รายชื่อนักเรียน:** นักเรียนที่ลงทะเบียนและจำนวนการจอง
- **สิทธิ์:** แก้ไข/ลบได้เฉพาะคลาสของตัวเอง
- **แถบแจ้งข้อจำกัด:** ถ้าถูกปิดปากหรือห้ามประกาศ จะมีแถบเหลืองด้านบนบอกเหตุผลและวันหมดอายุ

### 2.2 หน้านักเรียน (`/`)

- **กระดานคลาส** กรองตามครู สถานะ คำค้น และ "เฉพาะการจองของฉัน"
  - **แบ่งสามส่วน:** `7 วันข้างหน้า` (แผงเน้นแยกต่างหาก) → `คลาสที่ไกลออกไป` (เกิน 7 วัน) → `คลาสที่จบแล้ว` (ผ่านไปแล้ว พับไว้เป็นค่าเริ่มต้น เปิดได้ในคลิกเดียว)
  - แต่ละส่วนแสดงจำนวนของตัวเอง ถ้า 7 วันข้างหน้าไม่มีคลาสจะแจ้งให้ทราบ ถ้าไม่มีคลาสล่วงหน้าเลย ส่วนที่จบแล้วจะกางเอง เพื่อไม่ให้เปิดมาเจอหน้าว่าง
- **การ์ดแต่ละใบแสดง:**
  - ครู สถานะการเปิดสอน มีการอัปเดตหรือไม่
  - ช่องประกาศ (ไม่เกิน 100 ตัวอักษร)
  - แถบที่อยู่ Google: เขตเวลา IANA + ค่า GMT, เวลาท้องถิ่นของครู, เวลาท้องถิ่นของฉัน, สถานที่, ลิงก์ Maps, เพิ่มลง Google Calendar
    - **คลาสออนไลน์** เปลี่ยนเป็นแถบประชุม: 🎥 ชื่อแพลตฟอร์ม, รหัสห้อง/รหัสผ่าน, ปุ่ม **เข้าห้องประชุม** และลิงก์ปฏิทินชี้ไปที่ลิงก์ประชุม
  - ที่นั่งว่างและจำนวนที่จองแล้ว
- **จอง/ยกเลิกในคลิกเดียว** ระบบกันการจองซ้ำ คลาสเต็ม และคลาสที่ยกเลิกแล้ว
- **รายละเอียดคลาส:** ข้อมูลครบ ประวัติการเปลี่ยนแปลง และรายชื่อผู้จอง (เห็นเฉพาะครูเจ้าของคลาส)
- **ตารางรายสัปดาห์ (v3.2.2):** แถวคือเวลาเริ่มที่ประกาศจริง คอลัมน์คือจันทร์ → อาทิตย์
  - ทุกคลาสที่ประกาศจะเป็นการ์ดในช่องของตัวเอง ถ้ามีครูหลายคนในเวลาเดียวกัน ช่องนั้นจะแบ่งความสูงตาม**สัดส่วนความยาวคลาส**
  - ชี้เมาส์ที่การ์ดเพื่อดูตัวอย่าง แล้ว **จอง / ยกเลิก / เข้าห้องประชุม / ดูรายละเอียด** ได้ทันที คลิกเพื่อเปิดรายละเอียด
  - ช่องที่ไม่มีคลาสจะแสดง **จองไม่ได้** ไม่มีช่วงเวลาที่ "ไม่มีใครประกาศแต่จองได้" อีก
  - `‹ ›` เลื่อนสัปดาห์ สัปดาห์ที่ไม่มีคลาสมีปุ่ม "ไปสัปดาห์ที่มีคลาสล่าสุด" สัปดาห์ที่ผ่านแล้วมีแบนเนอร์แจ้ง
  - ต่ำกว่า 760px ตารางเปลี่ยนเป็น 7 การ์ดรายวัน ข้อมูลเหมือนกัน
- **หน้าเข้าสู่ระบบ:** แสดงข้อสงวนสิทธิ์ของแพลตฟอร์ม (ดูข้อ 12)

### 2.3 คอนโซลผู้ดูแลระบบสูงสุด (`/superadmin.html` แสดงเฉพาะ `is_admin`)

- **ภาพรวม:** บัญชีทั้งหมด / ครู / นักเรียน / ผู้ดูแล / ถูกแบน / ถูกปิดปาก / คลาส / การจอง
- **จัดการบัญชี:** ค้นหา (ชื่อ ชื่อผู้ใช้ เบอร์โทร) กรองตามบทบาทและสถานะข้อจำกัด
- **ดำเนินการกับครูหรือนักเรียนคนใดก็ได้:**
  - **แบนบัญชี**: เข้าสู่ระบบไม่ได้ทันที เซสชันที่เปิดอยู่จะหมดอายุในคำขอถัดไป
  - **ปิดปาก**: 1 ชั่วโมง / 24 ชั่วโมง / 7 วัน / 30 วัน / ถาวร ระหว่างนั้นประกาศหรือแก้ไขคลาสไม่ได้ นักเรียนจองไม่ได้
  - **ห้ามประกาศคลาส**: แก้ไขคลาสเดิมได้ แต่สร้างใหม่ไม่ได้
  - **ยกเลิกข้อจำกัดทั้งหมด**
  - **ตั้ง / ถอดผู้ดูแลระบบสูงสุด**, **รีเซ็ต PIN 4 หลัก**, **ลบบัญชี** (ลบคลาสและการจองที่เกี่ยวข้องตามไปด้วย)
- **ตรวจสอบคลาส:** ค้นหาคลาสทั้งหมด **นำลง** (เปลี่ยนเป็นยกเลิกและบันทึกประวัติ นักเรียนเห็นเหตุผล) และ**คืนค่า**
- **บันทึกการดำเนินการ:** ผู้ทำ การกระทำ เป้าหมาย เหตุผล เวลา
- **ป้องกันตัวเอง:** แบน/ลบ/ลดสิทธิ์ตัวเองไม่ได้ ผู้ดูแลด้วยกันจำกัดกันไม่ได้ และระบบต้องเหลือผู้ดูแลอย่างน้อยหนึ่งคน

### 2.4 ส่วนกลาง

- สลับ 4 ภาษา ข้อผิดพลาดจาก API ก็แปลตาม `X-Language`
- เข้าสู่ระบบ / ลงทะเบียนด้วย PIN 4 หลัก ครูใช้รหัสเชิญในการลงทะเบียน
- Google OAuth (ปุ่มจะแสดงเมื่อตั้ง `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` แล้วเท่านั้น)
- หน้าการสมัครปฏิทิน `/calendar.html`: ที่อยู่ ICS, JSON สาธารณะ, วิธีสมัคร
- มือถือ: การ์ดคอลัมน์เดียว ไดอะล็อกแบบ bottom sheet ตารางรายสัปดาห์เลื่อนแนวนอนได้ ปุ่มแตะขนาด ≥44px

## 3. เริ่มต้นอย่างรวดเร็ว

```bash
git clone https://github.com/zixiang2008/CMenglishClass.git
cd CMenglishClass
npm install
npm start
```

เปิด <http://localhost:3000>

การเริ่มครั้งแรกจะสร้าง `booking.db` สร้างตาราง และใส่บัญชีตัวอย่างพร้อมคลาสตัวอย่าง 4 คลาส

```bash
npm run dev                                  # เหมือน start
PORT=3210 DB_PATH=/tmp/x.db npm start        # อินสแตนซ์ชั่วคราวสำหรับทดลอง
```

## 4. บัญชีและข้อมูลตัวอย่าง

รหัสผ่านทั้งหมดเป็น **PIN 4 หลัก** และ **ชื่อผู้ใช้ไม่แยกตัวพิมพ์เล็ก-ใหญ่**: `Hamish`, `hamish`, `HAMISH` คือบัญชีเดียวกัน (การตรวจซ้ำตอนลงทะเบียนก็เช่นกัน)

**บัญชีใช้งานจริง**

| บทบาท | ชื่อผู้ใช้ | PIN | หมายเหตุ |
| --- | --- | --- | --- |
| **ผู้ดูแลระบบสูงสุด** / ครู | `elvis` | `1314` | สิทธิ์สูงสุด: จัดการทุกบัญชี แบน/ปิดปาก/ห้ามประกาศ ตรวจคลาส ดูบันทึก |
| ครู | `hamish` | `1234` | บัญชีครูจริง ยังไม่ประกาศคลาส |
| ครู | `kevin` | `1234` | บัญชีครูจริง ยังไม่ประกาศคลาส |

## 7. โมเดลข้อมูล

```sql
users            id, username, password_hash, display_name, phone, role, google_id,
                 is_admin, status, ban_reason, banned_at,
                 muted_until, mute_reason, publish_blocked, publish_block_reason
schedule         id, day_of_week, time_slot, status, booked_by, booked_name   -- ตาราง v2
courses          id, teacher_id, title, notice, notice_updated_at,
                 timezone, lesson_date, start_time, end_time, start_utc, end_utc,
                 mode, online_platform, online_url, online_note,          -- v3.3
                 place_name, google_maps_url, capacity, run_status, status_note,
                 revision, created_at, updated_at
course_bookings  id, course_id, student_id, status, created_at, cancelled_at
course_updates   id, course_id, teacher_id, change_type, summary, created_at
admin_actions    id, admin_id, admin_name, target_user_id, target_name,
                 target_course_id, action, detail, created_at   -- บันทึก v3.1
```

จุดออกแบบสำคัญ:

- `start_time` / `end_time` คือเวลาตามนาฬิกาท้องถิ่นของครู ส่วน `timezone` คือเขตเวลา IANA
- `start_utc` / `end_utc` คือเวลาจริงแบบ UTC ที่เซิร์ฟเวอร์คำนวณ การเรียงลำดับ ฟีด ICS และลิงก์ปฏิทินใช้ค่านี้ทั้งหมด
- `mode` เป็น `offline` (ค่าเริ่มต้น) หรือ `online`; `online_platform` เป็นหนึ่งใน
  `tencent_meeting / zoom / teams / google_meet / voov / dingtalk / wechat / other`
  `online_url` คือลิงก์ประชุม `online_note` คือรหัสห้อง/รหัสผ่าน (ไม่บังคับ ≤120 ตัวอักษร)
- ข้อมูลเดิมย้ายอัตโนมัติ: `ALTER TABLE courses ADD COLUMN mode TEXT NOT NULL DEFAULT 'offline'`
  อยู่ใน `try/catch` คลาสก่อน v3.3 ทั้งหมดจึงยังอ่านเป็นออนไซต์ และ `place_name` / `google_maps_url` ไม่หาย
- `run_status` เป็นตัวตัดสินว่านักเรียนจองได้หรือไม่
- เมื่อ `revision` มากกว่า 1 หน้าบ้านจะแสดงป้าย "มีการอัปเดต"
- `is_admin` แยกจาก `role` และเป็นสิทธิ์สูงสุดของระบบ `status='banned'` ห้ามเข้าสู่ระบบ
  `muted_until` ห้ามทุกการประกาศ `publish_blocked` ห้ามเฉพาะการสร้างคลาสใหม่
- เวลาจากฐานข้อมูลจะถูก normalize เป็น ISO-8601 UTC ก่อนส่งออก (เพราะ `CURRENT_TIMESTAMP` ของ SQLite ไม่มีเครื่องหมายเขตเวลา เบราว์เซอร์จะเข้าใจผิดว่าเป็นเวลาท้องถิ่น)

## 10. การติดตั้งใช้งาน

### 10.1 Render

`render.yaml` ในรีโปตั้งค่าไว้แล้ว:

- `buildCommand: npm install`
- `startCommand: node server.js`
- `NODE_ENV=production`
- `SESSION_SECRET` สร้างอัตโนมัติ
- `TEACHER_INVITE_CODE` ค่าเริ่มต้น `TEACHER2026` ควรเปลี่ยนก่อนใช้งานจริง

> แพ็กเกจฟรีของ Render ใช้ไฟล์ระบบชั่วคราว `booking.db` จะถูกรีเซ็ตทุกครั้งที่ deploy ใหม่ ถ้าต้องการเก็บข้อมูลถาวรให้ mount ดิสก์หรือย้ายไปฐานข้อมูลภายนอก

### 10.2 เครื่อง lokal + Cloudflare Tunnel (`en.caishen.today`)

สร้างทันเนล `english-class-booking` ไว้แล้ว:

```
Tunnel ID : 02e615a5-3b68-4052-9d03-45c7544f855d
Config    : ~/.cloudflared/english-class-booking.yml
Ingress   : http://localhost:3000
```

```bash
# เทอร์มินัล 1: แอป
cd /Volumes/OS2App/AiColding/english-class-booking
NODE_ENV=production PORT=3000 SITE_URL=https://en.caishen.today \
SESSION_SECRET='<สุ่มสตริง>' TEACHER_INVITE_CODE='TEACHER2026' node server.js

# เทอร์มินัล 2: ทันเนล
cloudflared tunnel --config ~/.cloudflared/english-class-booking.yml run english-class-booking
```

เพิ่ม DNS record นี้ในบัญชี Cloudflare ที่ถือโดเมน `caishen.today`:

| ชนิด | ชื่อ | เป้าหมาย | Proxy |
| --- | --- | --- | --- |
| CNAME | `en` | `02e615a5-3b68-4052-9d03-45c7544f855d.cfargotunnel.com` | เปิด proxy (เมฆสีส้ม) |

เริ่มอัตโนมัติเมื่อล็อกอิน (มี plist อยู่ใน `~/Library/LaunchAgents/` แล้ว):

```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.caishen.english-class-booking.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.caishen.english-class-booking-tunnel.plist

# หยุดและลบ
launchctl bootout gui/$(id -u)/com.caishen.english-class-booking
launchctl bootout gui/$(id -u)/com.caishen.english-class-booking-tunnel
```

ล็อก: `~/Library/Logs/english-class-booking/`

### 10.3 ใช้เฉพาะโดเมนในเครื่อง (ไม่เปิดสู่อินเทอร์เน็ต)

ต้องใช้ `sudo` หนึ่งครั้งเพื่อชี้โดเมนมาที่เครื่องนี้:

```bash

```

แล้วเปิด `http://en.caishen.today:3000` (แอปฟังพอร์ต 3000 ไม่ใช่ 80)

## 11. ระบบจัดการเขตเวลาอย่างไร

1. ครูกรอกวันที่ เวลาเริ่ม/สิ้นสุด และเขตเวลา IANA (เช่น `Asia/Bangkok`)
2. เซิร์ฟเวอร์ใช้ `Intl.DateTimeFormat` หาค่า offset ของเขตเวลานั้นในวันนั้น แล้ววนซ้ำสองถึงสามรอบให้ลู่เข้า (รองรับ DST) ได้ `start_utc` / `end_utc`
3. หน้านักเรียนใช้ `Intl.DateTimeFormat` แสดงเวลา UTC เดียวกันสองครั้ง:
   - เวลาท้องถิ่นของครู + ตัวย่อเขตเวลา
   - เวลาท้องถิ่นของเบราว์เซอร์นักเรียน + ชื่อเขตเวลา
4. ฟีด ICS และลิงก์ Google Calendar ใช้ UTC จริงในรูปแบบ `YYYYMMDDTHHMMSSZ` ผู้สมัครจะไม่เห็น "เวลาลอย"

กรณีขอบที่ตรวจแล้ว:

- `Asia/Bangkok` 10:00 → `03:00Z` (GMT+7)
- `America/New_York` ฤดูร้อน 09:00 → `13:00Z` (EDT)
- `America/New_York` ฤดูหนาว 09:00 → `14:00Z` (EST)

## 12. ความเป็นส่วนตัวและความปลอดภัย

- รหัสผ่านเก็บเป็น bcrypt hash คุกกี้เซสชันเป็น `httpOnly` และในโปรดักชันเป็น `secure` + `SameSite=None`
- รายการคลาสเปิดเผยต่อสาธารณะ แต่รายชื่อผู้จองเห็นได้เฉพาะครูเจ้าของคลาสนั้น
- ปฏิทินสาธารณะเปิดเผยเฉพาะสถานะ เวลา สถานที่ ลิงก์แผนที่ ประกาศ และชื่อครู ในตารางแบบเดิมชื่อนักเรียนย่อเหลืออักษรแรก
- ลิงก์ Google Maps ต้องเป็น `https` และอยู่ในโดเมน Google เพื่อกันการแทรกลิงก์ใด ๆ
- ช่องประกาศจำกัด 100 ตัวอักษรทั้งฝั่งเซิร์ฟเวอร์และฝั่งไคลเอนต์
- การเขียนคลาสทุกครั้งตรวจสอบความเป็นเจ้าของ `teacher_id`
- หน้าเข้าสู่ระบบแสดง**ข้อสงวนสิทธิ์ของแพลตฟอร์ม**: เว็บนี้เป็นช่องทางเผยแพร่ แสดง และรับจองข้อมูลคลาสของครูและนักเรียนในเชียงใหม่ ไม่ใช่ผู้ให้บริการสอน ข้อตกลงเรื่องคลาส ค่าใช้จ่าย คุณภาพ ความปลอดภัย และข้อพิพาทเป็นเรื่องระหว่างครูกับนักเรียน ครูรับผิดชอบคุณสมบัติ วีซ่า และใบอนุญาตทำงานของตนเอง และความรับผิดตามกฎหมายของแพลตฟอร์มไม่ถูกยกเว้นด้วยข้อความนี้
