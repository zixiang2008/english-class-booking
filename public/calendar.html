📱 Google Calendar
  1. Open Google Calendar
  2. Click + next to "Other calendars"
  3. Select From URL and paste the ICS URL above
  4. Click Add calendar
🍎 Apple Calendar (macOS / iOS)
  1. Open Calendar → File → New Calendar Subscription
  2. Paste the ICS URL, then set auto-refresh (e.g. every hour)
📧 Microsoft Outlook
  1. Outlook Calendar → Add calendar → From Internet
  2. Paste the ICS URL and confirm
